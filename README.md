# Trainer Landing — демо-шаблон лендинга фитнес-тренера

Portfolio demo: двуязычный (RU/EN) лендинг фитнес-тренера с записью на тренировки.

## Stack

Один самодостаточный `index.html` — весь CSS/JS и изображения инлайн, без сборки.

## Features

- Переключатель языка RU/EN в шапке — переводит весь контент
- Тёмная тема: чёрный фон, тёмно-серые карточки, бордовые кнопки
- Hero-секция с крупной CTA-кнопкой «почувствуй боль перемен»
- Программы: силовые тренировки, снижение веса, бокс
- Цены в USD, демо-отзывы
- Форма записи (имя, телефон, тип тренировки, дата/время) с валидацией и экраном подтверждения
- В коде помечена точка подключения реальной отправки (email/CRM)
- Адаптивная вёрстка, mobile-first

## Note

Персона тренера («Арнольд Арнольдович»), фото, цены и отзывы — вымышленные демо-данные для шаблона.

## Publish (GitHub Pages)

```bash
gh repo create trainer-landing --public --source=. --push
# затем: Settings → Pages → Deploy from branch → main → Save
# live at https://stehmen.github.io/trainer-landing/
```
